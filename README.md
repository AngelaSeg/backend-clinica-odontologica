# Backend Clínica Odontológica

Sistema de gestión para clínica odontológica. Actualmente en desarrollo.

## Tecnologías
- Java 17
- Spring Boot 3
- Spring Security (JWT)
- PostgreSQL
- Spring Data JPA
- Gradle

## Configuración local
1. Clonar el repositorio.
2. Renombrar `application-example.properties` a `application.properties`.
3. Configurar las credenciales de PostgreSQL y la clave JWT.
4. Ejecutar la aplicación.
